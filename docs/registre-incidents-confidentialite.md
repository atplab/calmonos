# Registre des incidents de confidentialité (Loi 25)

Responsable : Emmanuel Ricard — nextonset@pm.me

À tenir à jour pour **chaque** incident (accès non autorisé, perte, divulgation, fuite), même sans risque sérieux.
Si l'incident présente un **risque de préjudice sérieux** : aviser sans délai la Commission d'accès à l'information (cai.gouv.qc.ca) et les personnes concernées.

| Date de découverte | Date de l'incident | Description (ce qui s'est passé) | Renseignements concernés | Nb de personnes | Risque de préjudice sérieux ? (oui/non + pourquoi) | CAI avisée (date) | Personnes avisées (date) | Mesures prises |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

Conserver ce registre au moins 5 ans.
